# Bonsai Club

A serene, hand-drawn bonsai tree simulation game celebrating patience and mindful practice. Grow, prune, wire, and sculpt your living tree in a tranquil ambient digital garden.

## Features

- **Procedural Growth & Pruning**: Trim branches, guide direction, and shape your tree's foliage as it develops.
- **Bonsai Styles & Challenges**: Practice classic Japanese styles (Chokkan, Moyogi, Kengai) across multiple objective scenarios and free-growth sandbox modes.
- **Ambient Atmosphere**: Relaxing visual palette and peaceful soundscape designed for calm focus.
- **Pots & Display Customization**: Customize pots, soil types, and stands to complement your tree's composition.
- **100% Offline & Free**: Single self-contained HTML file running directly in the browser.

## Getting Started

Open `index.html` in any modern web browser or use it on https://jameop1.github.io/bonsai-game/
